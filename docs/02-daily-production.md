# Daily Production Cadence

Target: **10–20 finished videos/day** across all characters and accounts. This doc is the assembly line.

## Daily quota by character (starting allocation)

| Character | Videos/day | Formats | Funnel |
|---|---|---|---|
| Greg #2 (debunker) | 4–6 | debunk-flip 30s/60s | Wellness/detox |
| Dr. Becky + Jesse | 3–4 | duo authority debunk, remedy explainers | Wellness/detox |
| Greg #1 (dad) | 2–3 | porch testimonial, dad-joke remedy | MD Klean |
| Nicole (Glassier) | 2–4 | routine-collapse, amplify-then-collapse | Glassier Skin |
| Survivalist | 2–3 | survival hack, reverse-engineer builds | Survival ebook |

Adjust weekly based on account performance — reallocate quota toward whatever's converting, but no character goes fully dark (accounts die without cadence).

## The daily pipeline

1. **Scrape + score (morning).** Pull trending claims via scraper → score against `hooks/backlog.md` criteria → top up the backlog to ≥ 3 days of runway.
2. **Batch script.** Generate the day's scripts per character in one batch, each through its format spec and character file. Batch per character, not per format — voice consistency degrades when switching personas rapidly.
3. **QA gate.** Every script runs `engine/script-qa-checklist.md`. Fail = rewrite, not patch. This is the step that exists because "AI is building crap scripts" — nothing skips it, especially at volume.
4. **Shot plans.** QA-passed scripts get Seedance shot plans per the format spec (realism blocks from the `davemedia` skill are mandatory).
5. **Render + post.** Generate, review the render for character drift (wrong face/voice = burn it), post on schedule.

## Batching rules

- Scripts are written **backward from the funnel CTA** (see `engine/consistency-rules.md` — desired-outcome chaining). Pick the funnel first, then the flip, then the debunk, then the hook.
- One hook = one video. Never stack two debunks in one script to save a slot.
- Every 10th video slot is reserved for a **pure flip** (no debunk) to maintain the 2:1 ratio.

## Affiliate template lane (parallel to daily video production)

Alongside owned-channel videos, the intake pipeline (`affiliates/intake-pipeline.md`) converts the video library into affiliate templates in batch sessions — target 5–10 QA'd templates per session. Owned channels prove a format works; the affiliate feed multiplies it across ~80 faces. A hook that wins on Greg #2's account is a template candidate the same week.

## Weekly loop

- Review per-account retention + CTA click data. Kill formats that are dying, double winners.
- Refill `hooks/backlog.md` from scraper trends; retire hooks the audience has stopped recognizing.
- Character drift audit: re-read 3 random scripts per character against their bible file. Drift found = tighten the character file, not just the script.
