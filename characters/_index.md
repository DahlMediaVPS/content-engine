## Rules that apply to every character

- **Locked look.** Each file carries the canonical appearance block used verbatim in every image/video prompt. Never freestyle a character's face, age, or wardrobe.
- **Locked voice.** Vocabulary, sentence length, humor style, and forbidden phrases are per-file. Cross-contamination (Greg #1's jokes in Greg #2's mouth) fails QA.
- **One character, one account voice.** Characters can appear on multiple accounts, but a character never breaks their own persona to serve a format.
- **New characters** get a file here *before* their first script. No file, no script.
