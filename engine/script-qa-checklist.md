# Script QA Checklist

The gate between "generated" and "rendered." Every script, every day, no exceptions — this checklist is the reason volume doesn't turn into slop. **A script that fails any item gets rewritten, not patched.**

Run order: structure → voice → craft → claims. Fail fast at the top.

## 1. Structure

- [ ] Written backward from a funnel: names exactly one funnel, CTA matches that funnel's current offer
- [ ] Follows its format spec's clip structure and timing (`formats/`)
- [ ] 6-beat check passes for 60s scripts (`jasons-copywriting` beats: hook, claim loops, pivot, mirror, gate, exit)
- [ ] One hook, max one debunk, one flip, one CTA — nothing doubled up
- [ ] Hook is a claim the viewer has already seen (debunk formats) or stakes-first (survival)

## 2. Character voice

- [ ] Read the character's bible file, then the script: every line survivable in that character's mouth
- [ ] No forbidden-list violations (each character file's Forbidden section)
- [ ] No cross-contamination (Greg #1 jokes in Greg #2's script, Becky hyping, Nicole gushing)
- [ ] Duo scripts: each speaker doing their defined job (Jesse = viewer's doubt, Becky = mechanism)

## 3. Craft (consistency rules 1–3)

- [ ] Outcome chain is explicit: viewer's desired outcome → enumerated steps → funnel
- [ ] Every line has a job; filler openers/closers cut
- [ ] Flip/teach steps are numbered, doable from the script alone, with expected outcome + timeframe stated
- [ ] Every scene direction = action + object + visible result (no "demonstrates the hack")
- [ ] The on-camera action shows the exact claim the dialogue makes

## 4. Claims (consistency rules 4–5)

- [ ] No treat/cure/prevent language; remedies in tradition/practice framing, testimonials in experience framing
- [ ] Every number real and verified, or `[VERIFY]`-flagged — flagged scripts are BLOCKED from render
- [ ] Amplify anchors true and sourced
- [ ] No named/identifiable creators in debunks — claims only
- [ ] Survival: technique tested and works as demonstrated
- [ ] FTC block from `davemedia` applied for wellness/supplement/skincare

## 5. Pre-render

- [ ] Character appearance block copied verbatim from bible file into prompts
- [ ] Realism blocks applied (hard-flash for skin, macro raking light for food/materials)
- [ ] Text overlays specified per format spec

---

**Batch rule:** at 10–20 scripts/day, QA drift is the failure mode. Every batch, pick one random script and re-run this checklist cold *after* approval. If the re-check catches something the first pass missed, re-check the whole batch.
